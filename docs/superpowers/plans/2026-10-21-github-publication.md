## 文件职责

- 修改 `.gitignore`：排除凭据、环境、模型、图片、新闻内容、图注、缓存和运行输出，允许上传两个作者数据集的来源清单与固定样本索引。

- 新建 `deploy/searxng/settings.example.yml`：不含实例密钥的部署模板。
- 新建 `scripts/restore_data.py` 与相应测试：从官方 ZIP 或现有本地图片恢复固定样本，校验图片 SHA-256 并更新新副本的路径与证据输入哈希。
- 新建 `scripts/download_metadata.py` 与相应测试：从已验证的固定作者版本恢复两套各 1,000 条输入与初始作者图注，不覆盖现有文件。
- 新建 `data/*/sample-index.json`、保留来源 `manifest.json`：记录固定选样、官方 ZIP 成员与图片 SHA-256，不发布新闻正文或图片。
- 新建 `docs/paper/MAR-KDD-2026.pdf`：附带原论文，并在 README 说明作者、DOI 和论文声明的许可。
- 修改 `README.md`：增加克隆后重建步骤、大文件下载和明确的未上传内容说明。
- 新建本计划：记录发布与验证结果。

## 约束

- 上传全部必要代码，不只上传 README。
- 不提交 `.env`、`instance.env`、私人密钥或本机认证信息。
- 模型权重、环境和数据图片不进入普通 Git；在 README 给出官方来源、命令、落盘位置和校验方法。
- 新恢复脚本默认写入 `data-local/`；原地修改清单必须显式指定，不对当前实验执行。
- 使用仓库级 Git 作者配置，不改全局设置；远端已有内容时不强制覆盖。
